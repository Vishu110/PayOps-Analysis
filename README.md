# PayOps-Analysis

A production-inspired payment operations platform designed to simulate the operational workflows of modern payment processors.

## Goals

- Learn end-to-end payment flows
- Simulate realistic payment data
- Perform reconciliation and operational investigations
- Build production-quality SQL skills
- Develop automation using Python
- Prepare for Payments Analyst and Data Analyst roles

## Tech Stack

- PostgreSQL
- Python
- SQL
- Power BI
- Pandas
